# dotfiles

Personal dotfiles: zsh (Zim + Starship), nvim, iTerm2, and the Claude Code user config under `.claude/`.

## Layout

```
.zshrc                     # interactive shell: Zim, completions, sources zsh/*.zsh, Starship
.zimrc                     # Zim modules
.zprofile                  # login environment: PATH and exports only
zsh/git.zsh                # git helpers: gcm, grm, grc, gcd
zsh/aliases.zsh            # other aliases and functions
.config/starship.toml      # prompt
.config/nvim/init.vim
iterm2_profile.json
.claude/CLAUDE.md          # global preferences and standing rules for Claude Code
.claude/settings.json      # project settings for this repo
.claude/agents/            # empty; kept so ~/.claude/agents links and container mounts resolve
.claude/hooks/             # empty; kept for the same reason
.claude/skills/            # personal skills
.claude/commands/opsx/     # generated by `openspec` CLI
```

## Shell setup

Needs zsh (macOS default), [Starship](https://starship.rs) and a Nerd Font in the terminal (the iTerm2 profile uses MesloLGS NF). Zim installs itself on first start.

```sh
brew install starship
D=~/path/to/dotfiles
ln -sf $D/.zshrc ~/.zshrc
ln -sf $D/.zimrc ~/.zimrc
ln -sf $D/.zprofile ~/.zprofile
mkdir -p ~/.config && ln -sf $D/.config/starship.toml ~/.config/starship.toml
exec zsh -l
```

`.zshrc` finds `zsh/` through its own symlink, so the repo can live anywhere. Tools that only exist on some machines are behind existence checks. Put anything that must stay off this repo in `~/.zshrc.local`; it's sourced if present.

After removing a module from `.zimrc`, run `zimfw uninstall` to delete it from `~/.zim`.

## Shared config

Agents, the `github`/`gitlab`/`create-team`/`spec` skills, and all three PreToolUse hooks come from the [stefanwb/claude-shared](https://github.com/stefanwb/claude-shared) plugin marketplace (`claude-shared` and `guardrails` plugins), enabled in user settings. See that README for setup. Nothing is copied into this repo.
