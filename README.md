# dotfiles

Personal dotfiles: shell profile, nvim, iTerm2, and the Claude Code user config under `.claude/`.

## Layout

```
.claude/CLAUDE.md          # global preferences and standing rules for Claude Code
.claude/settings.json      # user settings, permissions, hook registration
.claude/hooks/             # PreToolUse hooks (dangerous-command block, protected files, agent spawn cap)
.claude/agents/            # installed copies from claude-shared (do not edit here)
.claude/skills/            # personal skills + installed copies from claude-shared
.claude/commands/opsx/     # generated by `openspec` CLI
bin/sync-claude-shared.sh  # refresh the installed copies from a claude-shared checkout
```

## Shared config

Agents, the `github`/`gitlab`/`create-team`/`spec` skills, and the `limit-agent-spawns.sh` hook are maintained in [stefanwb/claude-shared](https://github.com/stefanwb/claude-shared). Change them there, then pull the copies in:

```sh
bin/sync-claude-shared.sh ~/git-work/claude-shared
git diff .claude
```

Everything else under `.claude/` (CLAUDE.md, settings.json, the two original hooks, openspec and personal skills) is owned by this repo.
