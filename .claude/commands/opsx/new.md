name: "OPSX: New"

category: Workflow
tags: [workflow, artifacts, experimental]
---

Run the `openspec-new-change` skill.

The argument after `/opsx:new` is the change name (kebab-case), or a description
of what the user wants to build. If neither is given, ask what they want to build.
